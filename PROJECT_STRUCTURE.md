# Project Structure

The following structure shows how the Bilingual Customer Feedback Analysis using NLP project is organized. Files will be added to their corresponding locations as development and documentation are finalized.

```text
bilingual-customer-feedback-nlp/
│
├── README.md
├── PROJECT_STRUCTURE.md
├── nlp-proj-final-v2.ipynb
├── requirements.txt
├── .gitignore
│
├── docs/
│   ├── NLP_project_Report.docx
│   └── NLP_Project_Presentation.pptx
│
└── demo/
    └── README.md
```

## Directory Description

| File / Directory | Purpose |
|---|---|
| `README.md` | Project overview, features, technologies, and setup instructions. |
| `PROJECT_STRUCTURE.md` | Documents the planned organization of the repository. |
| `nlp-proj-final-v2.ipynb` | Main notebook containing the NLP implementation and analysis. |
| `requirements.txt` | Python dependencies required to run the project. |
| `.gitignore` | Specifies files and folders that should not be tracked by Git. |
| `docs/` | Stores project documentation and presentation materials. |
| `NLP_project_Report.docx` | Written project report. |
| `NLP_Project_Presentation.pptx` | Project presentation slides. |
| `demo/` | Contains information about the project demonstration. |
| `demo/README.md` | Provides the demonstration video link and a brief description. |
